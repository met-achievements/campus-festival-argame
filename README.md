# 怪盗からの挑戦状 ―バーチャルD館盗難事件―

学園祭ARゲームの2026年10月26日時点の本編です。9月21日の試作を基に、後半の台詞と演出、D館の調査表示、最終ゲームの速度と表示を改良しています。GitHub Pagesで公開する場合は、この一式をリポジトリのルートへ置き、Pagesの公開元をルートに設定してください。公開URLを開くと `Prototype/index.html` へ進みます。

## フォルダー運用

このプロジェクトでは`Game/`を公開用ゲーム一式の正本とする。今後は日付付きの最新版フォルダーを増やさず、公開する変更を`Game/`へ反映する。`Game.zip`は共有やアップロードが必要な時だけ、`Game/`と同じ内容で更新する。比較案や未採用の単体試作は`Prototype/`で管理する。

## スマートフォン・PC共通のデバッグメニュー

スマートフォンでもPCでも、各画面の右上の`DEBUG`を押してメニューを開けます。「ゲームに戻る（閉じる）」または右上の「閉じる ×」で、同じ画面へ戻ります。この開閉だけでは進捗を変えません。制限時間のあるゲームはメニュー表示中も進みます。

「画面を開く」からD館調査・B館・G館・最終ゲームへ直接移動でき、「本編画面へ戻る」で現在の進捗に応じた物語へ戻れます。「進捗を変更する」には従来の導入省略・クリア扱い・リセットをまとめています。制作確認用の機能で、通常の参加者向けスキップ機能とは別扱いです。キーボードの`Ctrl`＋`Shift`＋`D`、`Escape`でも開閉できます。

本編とD館調査では、DEBUG内の「D館の表示」で青の濃さを1→2→3→4→5→1の順に比較できます。端末ホームの小地図・調査地図・3Dへ共通で反映し、同じタブで画面を移動しても引き継ぎます。通常の参加者向け表示は採用した青1です。比較値は確認用の一時設定で、ゲーム進捗とは別に扱い、タブを閉じると解除されます。

開始画面 → エラー演出 → 探偵との会話 → タイトル画面 → 通信端末の受け取り → 最初の通話 → D館の指示 → 機械音声の操作案内 → 通信端末ホーム → D館調査、という導線を含みます。通信履歴と調査バッグも端末ホームから開けます。B館・G館のARと最後の仕分けゲームまで試作段階で接続しています。ARで使うカメラにはHTTPSが必要です。A-FrameとMindARは外部CDNから読み込みます。

これはフィードバック用の試作で、iPhone実機での通し確認、現地のARターゲット確認、素材の公開・再利用条件の最終確認は未了です。特に共同制作の素材やコードを公開リポジトリへ載せる前に、関係者の許可を確認してください。

## 後半ストーリー（2026年10月13日・統合済み）

- B館・G館の回収後にはそれぞれ着信が入り、応答すると探偵がJ館・E館で取り戻したデータを報告します。順番は自由で、一件目はお互いに残り一個、二件目で全体4/4と伝えます。着信を拒否してもかけ直せます。
- 二件目の通話中に怪盗が割り込み、遠隔ではシルエットを表示します。探偵との通話に戻って「聞こえたか？」から合流の話を続け、D館の看板の前への到着後に対面へ切り替わります。
- 探偵が自分で勝負を受け、最後の出題内容を聞いてからD館を調べた助手へ任せます。デモのゲーム省略・勝敗選択メニューは本編には入れず、実際の最終仕分けへ進みます。
- 最終ゲームの失敗時は怪盗の台詞と再挑戦を表示します。成功して本編へ戻ると、勝利・確保・再戦予告、復元確認4/4、公開再開、完成したD館とMETへの案内、クリア画面まで進みます。採点・制限時間・クリア条件は従来どおりです。速度は下記の5段階式へ変更しました。
- 途中再開と通信履歴に対応します。旧版のゲーム進捗・回収済みの状態を維持し、D館対面や結末の途中位置は新版の対応場面へ移します。旧版の回収報告の途中は、拡張した報告の冒頭から再開します。
- Clusterの共有URLは未設定です。確認済みの完成ワールドの共有URLを`Prototype/post-story.js`の`CLUSTER_WORLD_URL`へ設定すると、クリア画面から開けます。未設定の間は案内を準備中として表示します。

## 最終ゲームの速度（2026年10月14日・反映済み）

時間経過による加速をやめ、3連続正解ごとに一段速く、1ミスで一段遅くなる5段階へ変更しています。一枚が落ち切るまでの時間は、レベル1から順に2.85／2.55／2.25／1.95／1.65秒です。初期を含む5段階なので、初期から失敗なしなら3・6・9・12連続の後に上がり、12連続正解の次の一枚から最速になります。

ミスで連続正解数を0へ戻します。誤分類・本物の見逃し・フェイクの誤押しがミスです。フェイクを正しく見送った場合は、得点・レベル・連続数を保ちます。速度変更は次の一枚から適用し、再挑戦はレベル1・0連続へ戻します。

2026年10月15日、速度の上下は制作側の調整として通常画面から説明・レベル・上下の通知を外しました。参加者には正誤・得点・残り時間・目標点を示し、3連続ごとの節目に短い反応を出します。レベルと連続数の常設表示は`?debug=1`のときだけ確認できます。速度処理は同じです。

最速になった後も60秒終了まで続けます。終了時15点以上で勝利、正解+1・ミス−1・最低0点という採点は継続します。ランダムな速度や三枚の合計時間固定は、今回の方式へ加えません。試遊時は`Prototype/d-final-sorting/index.html?game=1`でAR読取を省いて始められます。

全体の本編は`index.html`から開きます。両館の回収報告とD館での対面会話の後に、この最新版の最終ゲームへ進み、勝利して戻ると事件の結末へつながります。全体の流れではAR読取を省く`?game=1`を付けません。五つのルール画面デモは未選択のため、既存の開始前画面を使います。

## D館の調査表示（2026年10月14日・青1を本編へ採用）

2026年10月15日、五地点の確認後は「探偵に電話をかける」から調査結果を報告する流れへ変更しました。電話では確認完了、W 至円と響在-高見観音のデータ盗難、その跡に一通ずつ残された手紙を順に伝え、通話を終えて二通を読みます。途中再開・通信履歴・記録への再確認に対応し、報告後の地図では「捜査を続ける」と表示します。

二通を読んだ後の通話は七台詞へ変更しました。探偵が手紙と行き先の対応を整理し、ゲームが待つという推測、二人の分担、自由順と報告を伝えてから送り出します。学園祭で会った来場者に協力してもらっている距離感で依頼し、「ありがとう。助かるよ。」で結びます。通話途中の再開に対応し、既に送り出しを終えた場合や回収を始めた場合は繰り返しません。

独立デモで選んだ青1を、地図・3Dデータ・端末ホームの小地図へ反映しています。表示面は薄い青、壁・文字と外側UIは深緑、操作は真鍮色です。四隅と不規則に上昇する青い走査光、原色の選択アイコンと短い反応を使用します。通常は青1で表示し、5段階の比較は本編DEBUG内でも行えます。上部に比較バーは置きません。直前の会話では、現実のモニュメントと端末内のバーチャルD館を見比べる調査を伝えます。

表示用の`Prototype/d-map-display.css`と`Prototype/d-map-display.js`も一緒に配置してください。元の地図や3Dモデルは加工せず、GLBと写真由来のSPZに合わせた表示フィルターを使います。SPZの通常版・盗難版とも同じ青1の補正です。選択アイコンは、地図上の元の中心位置で大きく表示します。

## D館の3Dデータ

後半の通信は前半と共通の電話画面、D館で合流した後は対面会話画面です。怪盗の手紙は一通ずつ開き、調査バッグから読み返せます。`Prototype/post-story.js`と`Prototype/post-story.css`も本編と一緒に配置してください。通話履歴と会話途中の進捗は同じブラウザー内に保存されます。

五地点の「この場所のデータを見る」で、指で回転・拡大できるバーチャルD館のデータを読み込みます。B館のクリアでW 至円、G館のクリアで響在-高見観音のデータが通常版へ切り替わります。回収報告などからD館マップへ戻って確認できます。

- `Assets/scaniverse/models/`の7ファイルを含めて配置してください。各モデルは開いた時だけ読み込みます（1点約3〜20MB）。
- 盗難用ファイルは`Center_D_Double_Ring_missing.spz`、`Center_D_stone_art_missing.spz`です。現状は暫定素材で、W 至円には輪が残り、高見観音は通常版と同内容です。あとで同名ファイルを差し替えてください。素材内容を自動で消したり修正したりする機能ではありません。
- 3DはHTTPSの公開URL、またはlocalhostのHTTPプレビューで確認してください。HTMLの直接起動（file://）では3Dを読み込めません。読み込み失敗時だけ試作用スキップを表示します。
- 表示依存：[Three.js 0.180.0](https://threejs.org/)、[Spark 2.2.0](https://sparkjs.dev/docs/)、[fzstd 0.1.1](https://github.com/101arrowz/fzstd)。外部配信を使用するためインターネット接続が必要です。SPZ 4はブラウザー内で旧形式へ可逆的に再梱包し、元ファイルは変更しません。[SPZ仕様](https://github.com/nianticlabs/spz/blob/main/README.md)。
